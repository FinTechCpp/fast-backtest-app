ChartDirector 7.1 (C++ Edition)

Chart.Cross2Shape

Usage

static int Cross2Shape(double width);

Description

Gets the shape id that represents a 'X' shape.

Please refer to Shape Specification for samples and more information on using shapes in ChartDirector.

Arguments

ArgumentDefaultDescription
width(Mandatory)The width of the arms of the a 'X' as a ratio to the size of the shape. Must be between 0 and 1.

Return Value

An integer shape id representing the a 'X' shape.
