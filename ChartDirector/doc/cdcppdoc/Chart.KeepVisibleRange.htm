ChartDirector 7.1 (C++ Edition)

Chart.KeepVisibleRange

Declaration

static const int KeepVisibleRange;

Description

A constant equals to 1 to represent that the viewport should be adjusted to keep the axis end points unchanged.

This constant is used in ViewPortManager.updateFullRangeH, ViewPortManager.updateFullRangeV
