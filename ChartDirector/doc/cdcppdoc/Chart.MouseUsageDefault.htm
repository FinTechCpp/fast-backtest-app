ChartDirector 7.1 (C++ Edition)

Chart.MouseUsageDefault

Declaration

static const int MouseUsageDefault;

Description

A constant equals to 0 to represent using the default mouse behaviour.

This constant is used in CChartViewer.setMouseUsage, QChartViewer.setMouseUsage and QmlChartViewer.setMouseUsage .
