QChartViewer.getUpdateInterval

Usage

int getUpdateInterval();

Description

Gets the minimum gap interval between two viewPortChanged signals in milliseconds.

Arguments

None

Return Value

The minimum gap interval between two viewPortChanged signals in milliseconds. See QChartViewer.setUpdateInterval for the meaning of this value.
