ChartDirector 7.1 (C++ Edition)

QmlChartViewer.defaultToolTip

Declaration

QString defaultToolTip

Description

Gets the the default tool tip to use when the mouse is over the QmlChartViewer but not over any hot spot.

This QML property maps to the C++ method QmlChartViewer.setDefaultToolTip.
