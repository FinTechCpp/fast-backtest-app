ChartDirector 7.1 (C++ Edition)

QmlChartViewer.mouseUsage

Declaration

MouseUsage mouseUsage

Description

Gets and sets the mouse usage mode.

This QML property maps to the C++ methods QmlChartViewer.getMouseUsage and QmlChartViewer.setMouseUsage.

Note that in QML, the C++ constants MouseUsageDefault, MouseUsageScroll, MouseUsageZoomIn and MouseUsageZoomOut need to be referenced as QmlChartViewer.MouseUsageDefault, QmlChartViewer.MouseUsageScroll, QmlChartViewer.MouseUsageZoomIn and QmlChartViewer.MouseUsageZoomOut.
