ChartDirector 7.1 (C++ Edition)

QmlChartViewer.zoomInHeightLimit

Declaration

double zoomInHeightLimit

Description

Gets and sets the viewport height at maximum zoom in.

This QML property maps to the C++ methods ViewPortManager.getZoomInHeightLimit and ViewPortManager.setZoomInHeightLimit.
