ChartDirector 7.1 (C++ Edition)

QmlChartViewer.zoomInRatio

Declaration

double zoomInRatio

Description

Gets and sets the magnification ratio for each zoom in click of the mouse.

This QML property maps to the C++ methods QmlChartViewer.getZoomInRatio and QmlChartViewer.setZoomInRatio.
