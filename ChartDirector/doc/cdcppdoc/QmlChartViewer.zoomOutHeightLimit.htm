ChartDirector 7.1 (C++ Edition)

QmlChartViewer.zoomOutHeightLimit

Declaration

double zoomOutHeightLimit

Description

Gets and sets the viewport height at maximum zoom out.

This QML property maps to the C++ methods ViewPortManager.getZoomOutHeightLimit and ViewPortManager.setZoomOutHeightLimit.
