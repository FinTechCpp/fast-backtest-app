QmlViewPortControl.viewPortExternalColor

Declaration

int viewPortExternalColor

Description

Gets and sets the the fill color for the region outside the viewport.

This QML property maps to the C++ methods ViewPortControlBase.getViewPortExternalColor and ViewPortControlBase.setViewPortExternalColor.
