Contour Plot Zoom/Scroll (Qt)



NOTE: This section describes Contour Plot Zoom/Scroll for Qt only. For MFC, please refer to Contour Plot Zoom/Scroll (MFC).

NOTE: For conciseness, some of the following descriptions only mention QChartViewer (for Qt Widgets applications). Those descriptions apply to QmlChartViewer (for QML/Qt Quick applications) as well.

This example demonstrates zooming and scrolling for a contour chart.

This example is similar to XY Zooming and Scrolling (Qt) except a contour chart is used instead of a scatter chart. It demonstrates considerations specific to contour charts:

  • By default, ChartDirector allows the x and y directions to independently zoom. For contour charts, it is common that the x and y directions need to zoom by the same factor. In this example, KeepAspectRatio is used in QChartViewer.setZoomDirection to keep the aspect ratio unchanged in zooming. This implies the x and y directions will zoom by the same factor.

  • In addition to the x and y axis, a contour chart also has a ColorAxis for the color scale. For color consistency, the color scale should remain unchanged during zooming and scrolling. This is the case if the color scale is configured using ColorAxis.setColorScale. If the color scale is not configured, ChartDirector will automatically determined the color scale based on the data points that are actually plotted. When the chart zooms or scrolls, the data points that are actually plotted will change, and this may change the color scale.

    To keep the color scale unchanged, in this example, the ColorAxis of the initial contour chart is saved to a member variable. When the chart zooms or scrolls, the updated chart will synchronize its color axis to that of the initial chart using Axis.syncAxis. The color axis in the smaller chart for the QViewPortControl will also synchronize with that of the initial chart. This ensures color consistency.
