Interactive Financial Chart



This example demonstrates a zoomable and scrollable financial chart with track cursor and support numerous technical indicators.

The main source code listing of this sample program is included at the end of this section. The code consists of the following main parts:

  • drawChart: This draws a finance chart based on the current data, the state of the viewport and the state of the user interface. When the viewport or the user interface changes, the corresponding event handler will call drawChart again the update the chart.

  • loadData: This loads the financial data to the current data arrays. It uses a random data generator to generate daily financial data for the main ticker symbol and the comparison ticker symbol. When the symbol changes in the user interface, the event handler will call loadData again to update the data.

  • trackFinance: This draws the financial chart track cursor on the dynamic layer of the chart. The OnMouseMovePlotArea event handler calls this method to ensure the track cursor follows the mouse.
