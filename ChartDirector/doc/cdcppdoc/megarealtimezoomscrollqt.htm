Mega Real-Time Chart with Zoom/Scroll and Track Line (Qt)



NOTE: This section describes Mega Real-Time Chart with Zoom/Scroll and Track Line for Qt only. For MFC, please refer to Mega Real-Time Chart with Zoom/Scroll and Track Line (MFC).

NOTE: For conciseness, some of the following descriptions only mention QChartViewer (for Qt Widgets applications). Those descriptions apply to QmlChartViewer (for QML/Qt Quick applications) as well.

This example demonstrates a real-time chart with a capacity of 3 x 10M data points, updating at 3 x 1000 points per second.

For demonstration purpose, this example will start with half of the data points already loaded. The other half will be filled with real-time data at a rate of 3 x 1000 points per second.

The charting, zooming, scrolling and track cursor part of the code is similar to Real-Time Chart with Zooming and Scrolling (Qt), which you may refer to for more details. In this example, we will focus on the code that handles the huge number of data points.

The main source code listing of this sample program is included at the end of this section. The code consists of the following main parts:

  • Initialization: The code uses 3 RanSeries objects to generate 3 random data series, each with 5M data points. To speed up, 3 threads are used to generate the random series in parallel.

  • The plotting will start when the "Plot Chart" button is pressed. This allows you to determine how much time is needed to plot the initial 3 x 5M points. Note that for performance testing, make sure the code is compile and run in "Release" mode, and run it without debugging (eg. use "Start without Debugging" in Visual Studio).

  • Data Acceleration: The first thing the plotting code does is to pass the data to the DataAccelerator for pre-processing. The DataAccelerator can significantly speed up chart plotting, especially if the chart needs to be updated or redrawn rapidly, such as for zoomable and scrollable charts and real-time charts. 3 threads are used to process the 3 data series in parallel.

  • drawChart: The drawChart code is similar to that in Real-Time Chart with Zooming and Scrolling (MFC), except the data are now supplied by the DataAccelerator.

  • OnChartUpdateTimer: This determines the chart update rate, which is set to 100ms in this example. In this example, we use a RanSeries object to generating data and store them in the data arrays. When the chart updates, it will commit the new data to the DataAccelerator by calling DataAccelerator.extendLength. In real applications, some other code should be used to acquire the data and store them in the data array. The data acquisition code can be triggered by another timer or run in a separate thread.
