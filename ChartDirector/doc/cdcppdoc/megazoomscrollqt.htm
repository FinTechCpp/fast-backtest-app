Mega Chart Zoom/Scroll (Qt)



NOTE: This section describes Mega Chart Zoom/Scroll for Qt only. For MFC, please refer to Mega Chart Zoom/Scroll (MFC).

NOTE: For conciseness, some of the following descriptions only mention QChartViewer (for Qt Widgets applications). Those descriptions apply to QmlChartViewer (for QML/Qt Quick applications) as well.

This example demonstrates a zoomable and scrollable chart with huge datasets containing 3 x 10M data points.

The zooming, scrolling and track cursor part of the code is similar to Zooming and Scrolling with Track Line (1) (Qt), which you may refer to for more details. In the following explanation, we will focus on the code that handles the huge number of data points.

  • Initialization: The code uses 3 RanSeries objects to generate 3 random data series, each with 10M data points. To speed up, 3 threads are used to generate the random series in parallel.

  • The plotting will start when the "Plot Chart" button is pressed. This allows you to determine how much time is needed to plot 3 x 10M points. Note that for performance testing, make sure the code is compile and run in "Release" mode, and run it without debugging (eg. use "Start without Debugging" in Visual Studio).

  • Data Acceleration: The first thing the plotting code does is to pass the data to the DataAccelerator for pre-processing. The DataAccelerator can significantly speed up chart plotting, especially if the chart needs to be updated or redrawn rapidly, such as for zoomable and scrollable charts and real time charts. 3 threads are used to process the 3 data series in parallel.

  • drawChart: The drawChart code is similar to that in Zooming and Scrolling with Track Line (1) (Qt), except the data are now obtained from the DataAccelerator using XYChart.addLineLayer3.
