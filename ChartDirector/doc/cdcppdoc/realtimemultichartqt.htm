Real-Time MultiChart (Qt)



NOTE: This section describes Real-Time MultiChart for Qt only. For MFC, please refer to Real-Time MultiChart (MFC).

NOTE: For conciseness, some of the following descriptions only mention QChartViewer (for Qt Widgets applications). Those descriptions apply to QmlChartViewer (for QML/Qt Quick applications) as well.

This example demonstrates a zoomable and scrollable real-time multichart with track cursor.

The example is modified from Real-Time Chart with Zooming and Scrolling (Qt) with the following changes:

  • Instead of an XYChart with 3 lines, this example draws a MultiChart containing 3 XYCharts, each with 1 line. The 3 charts are stacked and only the bottom chart has a visible x-axis.

  • The track cursor code is modified to use a loop to draw 3 track cursors on the 3 XYCharts.
