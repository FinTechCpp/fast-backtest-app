Detailed Description

Classe de base abstraite pour tous les panels de l'application.

Cette classe définit l'interface commune à tous les panels. Chaque panel spécifique doit hériter de cette classe et implémenter la méthode create() qui retourne un widget contenant l'interface du panel.
