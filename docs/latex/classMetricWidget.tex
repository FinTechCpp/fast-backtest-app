\doxysubsection{Detailed Description}
Widget pour afficher une métrique avec un titre, une valeur et une variation optionnelle. 

Ce widget est utilisé dans les vues de résultats pour afficher les statistiques du backtest de manière visuellement cohérente et attrayante.
