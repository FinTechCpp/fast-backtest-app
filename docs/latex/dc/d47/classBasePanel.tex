\doxysubsection{Detailed Description}
Classe de base abstraite pour tous les panels de l\textquotesingle{}application. 

Cette classe définit l\textquotesingle{}interface commune à tous les panels. Chaque panel spécifique doit hériter de cette classe et implémenter la méthode \mbox{\hyperlink{classBasePanel_a9f2dcd881091f932f822f46a49385b24}{create()}} qui retourne un widget contenant l\textquotesingle{}interface du panel.
